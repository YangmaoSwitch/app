# 羊毛switch 桌面端 / YangmaoSwitch App

> Windows 10/11 x64 安装包见 [官网下载页](https://yangmaoswitch.github.io/website/download.html)；macOS 和 Linux 版本之后提供。

用户自己的 **Key 管理和用量管理工具**：一站式查看各平台大模型免费额度，开通账号拿到 Key，在本机统一管理这些 Key，并记录、控制用量。羊毛switch 本身不提供、也不消耗任何模型服务。

## 功能

- **目录**：读取 [额度目录](https://github.com/YangmaoSwitch/catalog)，可按能否当 API 用、是否需手机号／信用卡／实名、能否一键开通等条件筛选。
- **开通**：
  - 支持 OAuth PKCE 的平台（首个是 OpenRouter）一键授权，自动拿到 Key。
  - 其余平台一键打开官方注册页或 Key 页；用户粘贴 Key 后，自动识别平台并测试。
- **Key 只存本机**：保存在系统钥匙串里，不上传。添加 Key 时可以改接口地址（如把 `ACCOUNT_ID` 换成自己的），但只能改成该平台自己域名下的 https 地址，Key 不会发到别处。
- **授权回调**：OpenRouter 一键开通和 GitHub 登录都回到本机一个一次性的随机地址（`/callback/<随机串>`），其他本机程序猜不到，无法冒充回调塞进别人的 Key 或登录凭据。
- **本地网关**：`http://127.0.0.1:<端口>`，兼容 OpenAI 和 Anthropic 接口，可供 Cherry Studio、Claude Code、Cline 等工具接入。
- **严格限量**：
  - 按目录里每家的额度口径在本机记账，留出安全余量（默认用到 90%）。额度只有 1 次这类太小的数量留不出余量，用量页会注明“按全额限量”。
  - 按 token 限量时，正在进行的请求（如长的流式输出）按已完成请求的平均用量预先计入，并发时不会一起冲过上限；流式输出中途断开、平台没报用量时，按请求大小和已收到的文字估算计入（宁可偏多）。
  - 平台提供剩余额度时，以平台数据为准。
  - 快到上限就停，或按设置切换到下一家，尽量避免超出免费额度。各平台的额度和计费规则以平台官方为准，请在平台控制台自行开启“用完即停”等保护设置。

## 不做

- 不代替用户填写验证码，不使用虚拟号码，不批量注册，也不多开账号。
- 不托管或共享 Key，不做中转。

## 使用本地入口

Key 填好后，工具只需接一个本机入口和一把本机密钥，选模型和换平台由羊毛switch 负责。

- Base URL：OpenAI 接口 `http://127.0.0.1:17890/v1`；Claude 接口 `http://127.0.0.1:17890`（不带 `/v1`）。
- API Key：“接入工具”页的本机密钥（首次启动随机生成，必填；页面上默认只显示前后几位，点“显示”看全文，“复制”总是复制完整的 Key）。它只用于 127.0.0.1 上的本机入口，和接入的工具一样保存在本机配置文件里；平台的 Key 才放系统钥匙串。
- 模型名：
  - `auto`：按模型广场的质量分从高到低，选你的账号能用的免费或免费额度模型（不走付费），并跳过不支持本次所需工具调用或图片输入的模型。
  - 模型广场里的模型名（如 `DeepSeek V4.1 Flash`）：只用这个模型，在所有提供它的账号之间切换，各家模型 ID 不同也可以。
  - 平台自己的模型 ID：按“我的账号”里的顺序使用提供它的账号。
  - `<账号>/<模型>`：固定用某个账号。
- 换下一家：到本地上限、429（按 Retry-After 暂停该账号，最长 1 小时，没有则 60 秒）、402（暂停 1 小时）、401/403（Key 无效，暂停 1 小时）、404（平台没有这个模型）、408/5xx（暂停 30 秒）、连接失败。只剩最后一个候选时原样返回平台的错误；一次请求最多尝试 8 次；已开始返回的流式结果不会中途切换。
- 实际使用的账号和模型写在响应头 `x-yangmao-served-by`。所有候选都不可用时返回 HTTP 429，错误码 `local_quota_reached`，消息里列出每家的原因。

## 开发

技术栈：Tauri 2（Rust）+ React + TypeScript。

```
crates/ym-core   目录模型、额度换算、本地账本、本地网关、模型路由（auto）、OAuth PKCE（不依赖 Tauri，可单独测试）
src-tauri        桌面端外壳：钥匙串、命令、启动网关
src              界面
```

```bash
npm install
cargo test -p ym-core      # 核心逻辑测试
npm run tauri dev          # 开发运行
npm run snapshot           # 发布前：把最新的目录数据打进安装包（src-tauri/*.snapshot.json）
npm run tauri build        # 打包
```

- 内置的目录数据只在首次启动、还没联网下载时使用，每次发布前用 `npm run snapshot` 更新（CI 打包也会先跑）。
- 左下角显示版本号和构建所用的提交（`v0.1.1 · abc1234`，工作区有未提交改动时带 `-dirty`），鼠标停留可看内置数据的日期。发布安装包时在官网 `static/download/<安装包>.json` 里写上同一提交，下载页会显示。
- 在浏览器里看界面：`npm run dev`（带示例数据），或 `npm run build:preview` 后 `npx vite preview`。正式构建（`npm run build`）不包含示例数据。
